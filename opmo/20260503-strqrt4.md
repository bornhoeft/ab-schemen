## Overview

**Schemen** derives its musical material entirely from the second movement of Schubert's String Quartet No. 14 in D minor, D. 810 (*Death and the Maiden*), measures 1 to 32. The piece generates the following Pure Data qlist text files for live sequencing:

**Duration files** (cue intervals per voice):

- `1-qlist.txt` – `4-qlist.txt`

**Synthesis parameter files** (per-cue settings per voice):

- `1-param.txt` – `4-param.txt`

**Spatialisation files** (8-channel octophonic field):

- `1-spat.txt` – `8-spat.txt`

---

## Structure

The piece consists of **32 measures** (128 quarter notes), divided into **8 sections** of 16 quarters each. At MM = 6 (10 sec/quarter), the total duration is **1280 seconds** (~21 min 20 sec).

Possible tempi:

| MM | sec/quarter | Total duration |
| --- | --- | --- |
| 60/8 | 7.5 sec | 16 min |
| 60/7.5 | 8 sec | 17 min 4 sec |
| **60/6** | **10 sec** | **21 min 20 sec** |
| 60/5 | 12 sec | 25 min 36 sec |
| 60/4 | 15 sec | 32 min |

## Duration Calculations

Each section distributes its total duration among a variable number of cues, drawn from a constrained random sum. Cue counts and ranges grow through the piece, condensing events from 4 to 14 and then relaxing back to 4:

| Section | Seed | Cues | Range (sec) |
| --- | --- | --- | --- |
| 1 | 1966 | 4 | 35 – 45 |
| 2 | 1914 | 5 | 20 – 35 |
| 3 | 1789 | 7 | 15 – 26 |
| 4 | 1968 | 10 | 10 – 22 |
| 5 | 1933 | 14 | 8 – 18 |
| 6 | 1989 | 9 | 10 – 26 |
| 7 | 2001 | 6 | 20 – 35 |
| 8 | 1958 | 4 | 35 – 45 |

Each section generates one shared duration list, which is then rotated\
for each of the four voices using `gen-rotate`:

```lisp
(loop with seed = (init-seed 1966)
      with durs = (rnd-sum-to-size sec-dur 4
                                   (step-lst 35 45 6))
      for i downfrom 0
      repeat no-voc
      collect (gen-rotate i durs))
```

The helper `step-lst` distributes n steps linearly between start and end:

```lisp
(defun step-lst (start end steps &key (round t))
  "Distribute n steps between start and end.
ex.
(step-lst 5 25 10) => (5 7 9 12 14 16 18 21 23 25)"
  (let ((norm (gen-transition 0 1 steps 1))
        (range (- end start)))
    (loop for i in norm
          for numb = (+ start (* i range))
          if round collect (round numb)
          else collect numb)))
```

The 59 cues total per voice are confirmed with:

```lisp
;; check: all sections sum to section duration
(loop for i in all-durs
      collect
        (loop for j in i
              collect (find-sum j)))
```

## Synthesis Parameters

Each cue receives a set of synthesis parameters. The envelopes and\
tendency curves evolve continuously across the 59 cues per voice.

**FM synthesis:**

| Parameter | Description |
| --- | --- |
| `-selfm2` | FM self-modulation mode (0 = +n Hz, 1 = f1+f2, 2 = abs(f1−f2)) |
| `-addfreq` | Frequency added to FM1 (Hz) |
| `-fm1` | FM1: carPartial, modPartial, index, lfo-freq |
| `-fm2` | FM2: carPartial, modPartial, index, lfo-freq |

**Noise / subtractive synthesis:**

| Parameter | Description |
| --- | --- |
| `-noise-q` | Filter Q for `vcf~` (noise synthesis) |
| `-synth-mix` | Mix between `osc~` (0) and `vcf~` (1) |

**Amplitude envelope:**

| Parameter | Description |
| --- | --- |
| `-env-curve` | Envelope curve shape (<1 concave, >1 convex) |
| `-dur-mult` | Envelope length relative to cue duration |
| `-env-mult` | Amplitude envelope multiplier |

The FM index tendency evolves from 1 to 200 and back to 100:

```plot1
(append
  (gen-transition 1 200 40 3)
  (rest (gen-transition 200 100 19 0.7)))
```

Synthesis mix follows individual sigmoid transitions per voice:

```plot1
(loop for i in durlens
      for c in '(0.4 0.5 0.6 0.7)
      collect (gen-sigmoid i :center c))
```

## Spatialisation

The piece uses an **octophonic speaker layout** on a 200 × 200 grid:

```lisp
(setf all-positions
  '((0 200)   ; FL / 1
    (100 200) ; FC / 2
    (200 200) ; FR / 3
    (200 100) ; CR / 4
    (200 0)   ; RR / 5
    (100 0)   ; RC / 6
    (0 0)     ; RL / 7
    (0 100))) ; CL / 8
```

Channels 1–4 carry the four direct instrument signals at fixed positions.\
Channels 5–8 carry the processed signals, which move through the space\
according to section-specific choreographies:

| Section | Movement |
| --- | --- |
| 0 | Reset to initial positions |
| 1 | Clockwise rotation through odd positions |
| 2 | Stepwise traversal of selected positions |
| 3 | Counter-clockwise rotation |
| 4 | Random sampling (seed 1977) |
| 5 | Independent random per channel (seed 1986) |
| 6 | Diagonal sweeps (right) |
| 7 | Channels 5/7 rotate right, 6/8 rotate left |
| 8 | Direct signals rotate clockwise; synthesis to even positions and stop |

Each section's spatialisation data is assembled into 8 qlist files\
using `matrix-transpose` across all sections:

```lisp
(setf spat-sections-ch
  (matrix-transpose
    (list spat-section0 spat-section1 spat-section2
          spat-section3 spat-section4 spat-section5
          spat-section6 spat-section7 spat-section8)))
;; check: all channels → 60 cues each
;; (60 60 60 60 60 60 60 60)
```

## File Output

Duration qlists are written to the Desktop as Plain Data messages:

```lisp
(loop for i in voc-durs
      for n from 1
      do (with-open-file (stream
            (concatenate 'string "~/Desktop/"
                         (write-to-string n) "-qlist.txt")
            :direction :output :if-exists :new-version)
           (format stream "~{~a;\n~}" i)))
```

Parameter and spatialisation files follow the same pattern,\
writing to `n-param.txt` and `n-spat.txt` respectively.
